# Results

This directory is reserved for lightweight result summaries and small generated artifacts.

Large generated files are ignored by default:

- trained models,
- TensorFlow Lite files,
- raw datasets,
- raw output CSV/PNG artifacts.

Keep reproducible commands and metrics in run-specific output directories under `outputs/`, or summarize stable findings here when they are small enough to track. Curated result figures under versioned subdirectories can be tracked when they are small and generated by committed scripts.
